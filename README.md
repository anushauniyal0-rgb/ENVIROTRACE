
🌿 ENVIROTRACE

Environmental Forensics & Pollution Analysis Platform

📌 Overview

ENVIROTRACE is a student-developed web project focused on environmental sample analysis and pollution-related information.

🎯 Problem Statement

Environmental pollution affects ecosystems and public well-being. Understanding environmental data can support awareness and informed decisions.

✨ Features

- Environmental information dashboard
- Sample analysis interface
- Pollution-related data presentation
- Interactive user interface

💻 Technologies Used

- HTML
- CSS
- JavaScript
